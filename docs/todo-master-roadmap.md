在 `v0.3.7` 基线上，本轮工作区已集中落地并准备随 **`v0.4.0`** 统一发布的核心能力：

1. **全站 UI v3.0 视觉体系与导航收口**：

   - 「联系作者 (X)」名片已回填真实账号 `@Caesar_LastKing`；「系统设置 → 版本更新」集成 Clash Verge Rev 安装检测与一键下载/启动入口；
   - 控制台探针实测数据 100% 全量中文化与层次重构；账户审计顶部身份区重构并记录历史账号订阅方式；**「Clash 断连回传 Cookie 403 防护」正式升格为「官方红线」**。
2. **毫秒级零开销混合热熔断守护 + 节点 72h 长效缓存**：
   - 新增 Win32 原生进程退出监听（`OpenProcess + WaitForSingleObject`，`<10ms`）与网卡变更监听（`NotifyIpInterfaceChange`，`<10ms`），策略/模式/禁区雷达提速至 `1s`；

3. **云端脱敏日志上报与排障单号闭环（`diag-worker/`）**：

4. **智能更新降噪分级 + 升级轻提示 + 文档脱敏**：
   - 落地 `update-state.json` 4 小时节流、取消静默检查右下角 Toast、**顶栏大/小版本分级静默**（仅主/次版本更新或含 `[重要]/[安全]/[紧急]` 标记才亮 `✨ 新版本发布！！`）；
