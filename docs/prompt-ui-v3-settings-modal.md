### 3. 四个子页具体规格（1:1 对齐 `docs/mockups/ui-v3-settings-modal-preview.html`）

#### (1) 常规开关（`general`）
1. **悬浮窗、通知与开机自启**：
   - `显示桌面悬浮状态窗`（推荐开启）
   - `桌面预警消息提醒`（推荐开启）
   - `开机自动启动 FD Claude 安全启动器`（推荐开启）
   - `开机时仅显示桌面悬浮窗`（推荐开启，**平铺对齐不加左缩进留白**；当「开机自动启动」关闭时置灰禁用并提示前置依赖）
2. **开机启动项检查**（只读检测，对接现有 `startupAudit` 真实数据）：
   - `Clash Verge` / `Claude Desktop` / `FD Claude 安全启动器`
   - 右侧状态胶囊统一为 3 字等宽（`已开启` / `未开启`），说明文案开头直接说清楚 `建议开启` 或 `建议关闭` 及原因。
3. **诊断日志与隐私**：
   - 开关：`允许自动上传脱敏诊断日志`（**当前后端暂无上传端点，见下方第 5 节待定项诚实降级规则**）
   - 系统常驻灰蓝锁定行：`敏感信息自动脱敏处理`（说明自动打码邮箱、Cookie、密钥与本机路径，不采集对话与代码）
   - 工具行 `手动排查与日志工具`：右侧按钮对接现有真实 IPC：`日志目录`（`openLogDir`）、`导出 AI 诊断包`（`exportAiDiagnosticBundle`），以及 `主动上传`（按第 5 节待定项诚实规则处理，绝不报假成功）。

#### (2) 安全策略（`policy`）
1. **顶部拆分为两张独立卡片（不可合并在一张卡里）**：
   - **上方独立卡片（原理介绍卡）**：`核心特色 · 4 层纵深防护与 2 秒热熔断闭环`，右侧注释 `灰蓝开关为系统常驻 · 亮蓝开关可按需调节`；下方横向 4 步流程图（零省略号、第 3 步轻柔丹红强调）：
     1. `启动前拦裸奔`（必须项未全绿禁止直连）
     2. `运行中锁链路`（业务域入 Fixed + 查脱组）
     3. `2 秒自动热熔断`（掐流 + 防火墙封出站）
     4. `强杀防回传`（清遥测 + 250ms 盯防）
   - **下方独立区块（用户紧急措施）**：
     - 区块头：`用户紧急措施` + 状态胶囊（正常时苔绿 `自动守护待命`，熔断激活时柔丹红 `熔断封锁中`），右侧提示文案固定为：**`自动检测并触发，极端异常时用户也可手动触发`**。
     - 独立卡片：`4 层紧急熔断控制 ⓘ` + 说明 + 右侧 31px 柔丹红实底主按钮，默认文案固定为 **`手动触发熔断`**（熔断激活后切换为幽灵按钮 `解除熔断保护`），对接真实 Kill-Switch IPC。
2. **L1 ~ L4 全链路纵深防护（按真实防护因果顺序排列，内置常驻项 + 用户可调项全部诚实呈现）**：
   - **L1 入口防线 · 启动前与切网拦截**：
     1. `启动前必须项硬门禁`（常驻开启·灰蓝锁）
     2. `防裸奔自动接管`（推荐开启·对接 `antiNakedGuard`）
     3. `休眠唤醒 / 切网 15 秒预阻断`（推荐开启·对接 `wakePreblockGuard`）
   - **L2 链路防线 · 业务域锁 Fixed 与防串线**：
     1. `业务域名与桥接进程自动同步至 Claude-Fixed`（常驻开启·灰蓝锁，写清自动同步 Claude 全家桶域名、KYC 域与桥接进程并拦截 14 条遥测域）
     2. `同步锁定人机盾与 Stripe 支付至 Claude-Fixed`（推荐开启·对接 `lockCfAndStripeToClaude`）
     3. `实时连接脱组监测与落地 IP 漂移审计`（常驻开启·灰蓝锁）
     4. `新号 / 刚付费 24h 冷静保护`（按需开启·对接 `calm24h`）
   - **L3 断流防线 · 实时监测与 2 秒热熔断**：
     1. `事件驱动 + 15 分钟全量巡检双引擎`（常驻开启·灰蓝锁）
     2. `异常自动紧急断流（4 层热熔断）`（推荐开启·对接 `autoKillSwitch`）
   - **L4 收口防线 · 防回传、进程防复活与自愈留痕**：
     1. `熔断恢复前强杀并清遥测缓存`（仅熔断生效·对接 `antiUploadFlush`）
     2. `强杀防复活盯防时长（Kill-Hold）`（`30s / 45s / 60s` 分段器·对接 `killHoldSeconds`）
     3. `事务级押运锁与卸载 / 退出自愈`（常驻开启·灰蓝锁）
     4. `安全退出防呆提醒`（推荐开启·对接 `safeExitPrompt`）
     5. `72h 风控日志归因审计`（常驻开启·灰蓝锁）

#### (3) 清理恢复（`recovery`）
- 页头副标题为 4 个快捷滚动定位锚点：`网络急救 · 配置撤回 · 本地清理 · 历史快照`。
- **区块 1：网络急救**（融合原「防自锁救援」）：
  - 主卡片 `一键恢复上网与防自锁救援 ⓘ`；右侧两枚按钮：次按钮 `仅清防火墙`（对接 `cleanupKillSwitchFirewall`）、主按钮 `一键网络急救`（对接 `runNetworkEmergencyRescue`，死 DNS 告警时升格为柔丹红实底）。
- **区块 2：配置撤回**：
  - 区块头 `配置撤回` + `已改动 N 项`，右侧 `刷新` + `撤回全部 (N)`。
  - 逐行展示基线项（Clash 规则、系统网卡 IPv6、浏览器 QUIC、系统 DNS），所有行尾按钮统一 2 字 **`撤回`**；未改动项状态标 `未改动`，其 **`撤回` 按钮置灰不可点击**，保持整列对齐一致。
- **区块 3：本地清理**：
  - `强杀并清待上传遥测缓存 ⓘ`（`仅应急` + `应急清理`）
  - `退出登录并清理本地污染目录 ⓘ`（`仅备份快照` + `退出并清理`）
- **区块 4：历史备份快照**：
  - 5 列等距紧凑表（`备份文件` / `类型` / `创建时间` / `体积` / `操作`），确保最右侧 `一键还原` 与 `删除` 在弹窗宽度下 0 裁切、0 溢出。

#### (4) 版本更新（`update`）
- **客户端版本与签名更新**：卡片呈现当前版本、检查更新状态、`检查更新`、`GitHub 官网` 按钮、Ed25519 验签说明及 MIT 开源脱敏声明，完整复用现有 `checkForUpdates` / `installUpdate` / 进度条逻辑。
- **联系作者与社区交流**：

  - **右侧仅保留单个 `前往 X 主页 ↗` 按钮（不要放 `查看名片弹窗` 按钮）**，点击调用系统浏览器打开作者 X 主页。
