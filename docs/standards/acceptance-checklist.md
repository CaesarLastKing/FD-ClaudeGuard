# FD Claude 安全启动器 · 验收阶段标准化手册与发版签收表（Acceptance Checklist）

> **文档编号**：`FD-STD-003`  
> **所属总纲**：[`docs/standards/engineering-lifecycle-sop.md`](./engineering-lifecycle-sop.md)（对应门禁 `G3`、`G4`、`G5`、`G6`）  
> **核心铁律**：**浏览器预览验收（关卡 A）只能验 UI 排版，绝不能替代真机 EXE 验收（关卡 B–D）！四道关卡全量打勾前，禁止对外发布安装包。**

---

## 1. 验收流程总览

每次里程碑交付或正式发版，必须严格按 **`关卡 A → 关卡 B → 关卡 C → 关卡 D`** 顺序执行验收，并逐项记录实测证据（截图路径、耗时、内存、状态码）：

1. **关卡 A（`G3`）· Web 1:1 视觉与交互自审**：验证全部页面、弹窗、抽屉、深浅双主题、极限数据、HUD 零偏移与 `console.error === 0`。
2. **关卡 B（`G4`）· Windows 真机运行态、多缩放与外部扰动验收**：在真实 Windows 11 桌面运行打包后的 Release EXE，验多 DPI + `130% 文本缩放`、4 处图标、外部操作同步、无黑窗、单实例、性能与极速退出。
3. **关卡 C（`G4/G5`）· 商业授权双态与云端真码验收**：逐项比对未激活态零泄密与已激活态全功能闭环。
4. **关卡 D（`G5`）· NSIS 安装 / 覆盖升级 / 彻底卸载全生命周期验收**：真实走完“干净安装 → 激活 → 覆盖升级保凭证 → 彻底卸载全清零”完整闭环。
