Claude 网页端状态字段与防封观测参考

梳理每个只读接口字段的风控语义，以及避免“观测本身触发封号”的操作红线。

1. 核心状态与风控信号对照
字段 / 端点 正常态特征 风险 / 受限含义
HTTP 403 / 401 (非 CF) HTTP 200 JSON 上游明确拒绝会话，属于凭据失效或账号已被封禁。
cf-mitigated: challenge 无此头 被 Cloudflare 边缘人机校验拦截，并非账号死亡，请更换干净代理或降低频率。
org.api_disabled_reason null 主组织已被风控禁用，常见于滥用检测、支付争议或政策违规。
org.billable_usage_paused_until null 计费与付费额度被临时暂停至指定时间戳。
kyc.status not_required / approved 若为 pending / created / needs_review / expired / denied，则属于订阅侧 KYC 受限。
portal.hold_notice null 组织 Portal 侧存在挂起通知，往往先于彻底 403 封号出现，是最重要的前兆信号之一。
chat_conversations?limit=1 HTTP 200 若组织接口 200 但对话域返回 403/400，说明存在局部功能封禁或对话权限受限。
usage (five_hour / seven_day) 低/中利用率 高频持续满载（>85%）叠加新号/共享机房 IP，往往更容易触发风控复核。
2. 避免“观测者效应”的低风控自测守则
守则 1
纯只读、低频单线程：本工具默认并发为 1、间隔 600ms，绝不做高频并发轮询，日常跟踪建议每天最多 1 次或仅在状态异常时手动触发。
守则 2
保持固定干净出口：探测账号时请使用该账号平时登录的同一地区/固定节点（如 Clash 固定单节点），避免跨洲/机房脏 IP 探测本身诱发风控。
守则 3
强脱敏导出再排查：若某账号返回了未知新字段需要进一步分析，请使用「复制强脱敏诊断包」功能，系统会自动清除 key、邮箱、姓名与真实 UUID 后再导出。
